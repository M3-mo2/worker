# بوت تحميل الفيديوهات من يوتيوب 


(يعتمد علي مكتبه gold-dl بتاعت صديقي فولت)

## المميزات ✨

- تحميل من يوتوب ب اي جوده تقريبا (360p, 720p, 1080p)
- تحميل الصوت فقط (MP3)
- دعم تحميل قوائم التشغيل كاملة
- اوبن سورس قابل للتوسع

## المتطلبات 📋

- Python 3.8 أو أحدث
- تليجرام بوت مع توكن
# تثبيت مكاتب + تهئيه

ثبت مكاتب من امر دا : 

```bash
pip install -r requirements.txt
```

هتنسخ ملف env.example وضيفه باسم env عشان تعدل عليه وتضيف توكن بوتك
```bash
copy .env.example .env
```

4. عدل ملف env وضيف توكنك
```env
BOT_TOKEN=your_bot_token_here
MAX_FILE_SIZE_MB=50
MAX_PLAYLIST_SIZE=20
DOWNLOAD_TIMEOUT=300
CLEANUP_INTERVAL=3600
```

## امر تشغيل البوت 

```bash
python main.py
```

## الاستخدام 📱

1 - دوس start
2 - ابعت الرابط (فيديو او بلاي ليست)
3 - اختار الجوده
4 - انتظر التحميل

## اوامر البوت 💬

- `/start` - بدء البوت
- `/help` - عرض معلومات المساعدة

## الإعدادات ⚙️

تقدر تخصص اعدادات من ملف `.env`:

- `BOT_TOKEN` - توكن البوت من BotFather (إجباري)
- `MAX_FILE_SIZE_MB` - الحد الأقصى لحجم الملف (افتراضي: 50 ميجابايت)
- `MAX_PLAYLIST_SIZE` - الحد الأقصى لعدد الفيديوهات في قائمة التشغيل (افتراضي: 20)
- `DOWNLOAD_TIMEOUT` - مهلة التحميل بالثواني (افتراضي: 300)
- `CLEANUP_INTERVAL` - فترة تنظيف الملفات المؤقتة بالثواني (افتراضي: 3600)
