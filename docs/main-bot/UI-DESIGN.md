# Main Bot — تصميم الواجهة (Telegram)

## القاعدة الأساسية

تيليجرام = رسالة نصية + أزرار تحتها. مفيش صناديق، مفيش frames. الكلام بيتكتب بـ Markdown والأزرار بتتحط تحته.

---

## /start — أول مرة

**الرسالة:**

> أهلاً بيك 👋
>
> أنا بوت الاستضافة — بساعدك تشغّل بوت تيليجرام بتاعك من ملف PHP في دقايق.
>
> كل اللي محتاجه: ملف PHP + توكن البوت من @BotFather

**الأزرار:**

```
[🚀 نشر بوت جديد]  [📋 بوتاتي]
[❓ مساعدة]
```

## /help

**الرسالة:**

> 📖 إزاي تستخدم البوت
>
> النشر:
> 1. اضغط `نشر بوت جديد`
> 2. ارفع ملف الـ PHP بتاعك
> 3. ابعت توكن البوت من @BotFather
>
> الأوامر:
> `/bots` — عرض كل بوتاتك
> `/status` — حالة البوتات
> `/deploy` — نشر بوت جديد
>
> لو البوت مش بيرد، تأكد إن التوكن صح وإن الملف مفيهوش أخطاء.

**الأزرار:**

```
[🚀 نشر بوت جديد]
```

## Stop — تأكيد

**الرسالة:**

> ⏸ إيقاف `{bot_username}`
>
> لو وقفت البوت مش هيستقبل رسائل، بس الملفات هتفضل موجودة.
>
> ممكن تشغله تاني في أي وقت.

**الأزرار:**

```
[⏸ وقّف البوت]  [❌ لا خلاص]
```

## Stop — تم ✅

**الرسالة:**

> ✅ تم إيقاف `{bot_username}`
>
> البوت موقف دلوقتي. ممكن تشغله تاني من بوتاتك.

**الأزرار:**


## Delete — تأكيد

**الرسالة:**

> ⚠️ حذف `{bot_username}`
>
> لو حذفت البوت:
> • الـ webhook هيتشال من تيليجرام
> • الملف هيتحذف من السيرفر
> • التوكن هيفضل شغال — ممكن تستخدمه تاني
>
> الإجراء ده نهائي.

**الأزرار:**

```
[🗑 احذف البوت]  [❌ لا خلاص]
```

## الـ Callback Data Convention

```
manage:view:123            ← عرض تفاصيل بوت
manage:stop:123            ← إيقاف بوت
manage:start:123           ← تشغيل بوت
manage:delete:123          ← طلب حذف
manage:confirm:delete:123  ← تأكيد الحذف
manage:cancel:123          ← إلغاء
manage:back                ← رجوع للقائمة
```

---

## الـ FSM States

```
IDLE (افتراضي)
  │
  │ /deploy
  ▼
WAITING_FILE ← مستني ملف PHP
  │
  │ يرفع ملف
  ▼
WAITING_TOKEN ← مستني التوكن
  │
  │ يبعت توكن
  ▼
IDLE ← يرجع للحالة الطبيعية
```

في أي وقت: `/cancel` أو زر إلغاء بيرجع لـ IDLE.
